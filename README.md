# Haunted Manor – Object-Oriented Text Adventure Game

## Overview

Haunted Manor is a Java-based text adventure game where players explore interconnected rooms, interact with characters, collect items, and solve puzzles to progress through the story.

The project demonstrates object-oriented design principles including encapsulation, modular class structure, state management, and command-based user interaction.

---

## Gameplay Features

- Multi-room navigation system
- Interactive characters and objects
- Inventory management
- Puzzle-driven progression
- Command-line input parsing

---

## Technical Highlights

- Object-oriented architecture with separate Room, Player, Item, and Game logic classes
- Modular command processing system
- Clear separation of game state and interaction logic
- Built and packaged using Maven
